  • 電腦鍵盤：方向鍵、Enter、Esc＝左軟鍵、Backspace＝右軟鍵、0–9、*、#
  • ◀ ▶ 永遠是換分頁：首頁「關注｜全部作物」、詳情「走勢｜行情｜比價」
  • * 永遠是批發／零售；# 是這一頁的選項，鍵帽畫在它控制的東西旁邊

這一版改了什麼

  • 首頁兩個分頁「關注｜全部作物」：打開就看到關注作物的價格；◀ ▶ 切到九宮格瀏覽全部作物，兩者同一層。
  • 拿掉按鍵提示列：每個按鍵只在一個地方提示，就在它控制的東西旁邊：* 在批發／零售標籤旁、# 在地區名稱或切換鈕旁、◀ ▶ 在分頁兩側。
  • 刪掉重複：首頁不再每列寫「今日」和市場數；連線失敗只標一次「舊」；比價的排序合成一個標籤；選單拿掉「瀏覽作物」，「關於」和「資料說明」合併。
  • 地區清單最後加「更改國家…」：比價只在同一個國家內，要看別國就整個切過去。

設計原則

  • 以地區為單位：台灣是縣市、印度是縣；地區批發價是各市場代表價的中位數，並標出市場數。
  • 按鍵意義固定：◀ ▶ 換分頁、* 批發／零售、# 這一頁的選項、1–9 直接開啟、左軟鍵選單、右軟鍵返回。
  • 誠實的資料：缺資料就說缺，不用 0 補；中位數、直線距離、「批零差額不是利潤」寫在「關於與資料說明」。
