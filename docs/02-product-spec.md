# 02 產品規格

> 功能範圍、畫面、按鍵規則、狀態與驗收條件。視覺與互動的參考實作是 [`ui-mockup/index.html`](ui-mockup/index.html)（「全部畫面」模式可一次看完所有畫面）。
> 版面與樣式細節見 [03](03-ux-ui.md)；API 與資料見 [04](04-architecture.md)、[06](06-data.md)。

## 1. 定位

- **核心任務**：
  1. 打開就看到「我這個地區、我關注的作物」今天多少錢、比前一個交易日漲還是跌。
  2. 看一個作物的近期走勢，以及它在各地區的價格排行。
- **使用者**：小農（賣方）、商販（進貨也出貨）。App 不區分角色，排序方式由使用者自己選。
- **即時的定義**：當天最新可得的行情。每個價格都標出交易日；不是當天的資料要明確標示。

## 2. 核心概念【決定】

| 概念 | 規則 |
|---|---|
| 國家 | 使用者先選國家（印度、台灣）；幣別、單位、地區清單、作物清單都依國家而定。比價只在同一國家內 |
| 地區 | App 的基本單位。台灣＝縣市，印度＝縣。每個地區有中心座標（用來算直線距離） |
| 市場 | 地區底下的批發市場，只在「本地區各市場」和「單一市場」畫面出現 |
| 價格類型 | 批發、零售。全站用 `*` 切換，目前的類型永遠顯示在畫面上 |
| 地區批發價 | 地區內**當天有報價**的市場代表價的中位數，同時顯示市場數 |
| 地區零售價 | 地區的零售調查價；零售沒有市場細項 |
| 我的地區 | 首頁使用的地區，存在本機。詳情頁可以暫時看別的地區，不會改掉「我的地區」 |

### 3.2 加分項【決定：順序】

baseline 完成並通過 Simulator 測試後，依下列順序做。語音與電腦版網頁依團隊決定（2026-09-19）排在最後；Serverless 與託管資料庫最後再討論（見 [05](05-tech-stack.md) §5）。

| 編號 | 功能 | 備註 |
|---|---|---|
| B1 | CD：GitHub Actions 自動部署 | 直接對應評分的 CI/CD；沿用手動部署腳本，成本低 |
| B2 | 真實資料：台灣農業部批發行情 | 不需金鑰，評審可以當場核對 |
| B3 | 真實資料：印度 data.gov.in 批發 | 需要免費 API 金鑰，第一天就去申請 |
| B4 | 真實零售資料 | 印度消費者事務部、台灣物價查報；取得方式【待確認】 |
| B5 | 國際參考價 | 選單進入的獨立頁；一條世界銀行月資料系列（小麥或稻米） |
| B6 | 印地文翻譯 | 需要母語者檢查 |
| B7 | 電腦與智慧型手機版 RWD + PWA | 對應評分的 RWD、PWA；PWA 只在一般瀏覽器有意義，所以和電腦版綁在一起；Cloud Phone 上不註冊 Service Worker |
| B8 | 語音播報 | 行情頁按 `0`；伺服器合成語音檔、用 `<audio>` 播放 |

### 3.3 不做【決定】

使用者輸入出價、夜間主題、到手價（扣運費估算）、賣方／買方角色設定、金流與交易撮合、帳號密碼、GPS、推播、離線、跨國比價、價格預測、AI 摘要、自由文字搜尋。

## 4. 按鍵規則【決定】

每個按鍵的意義在全 App 固定；只有 `#` 依頁面不同，而且畫面上一定會把 `#` 的鍵帽畫在它控制的東西旁邊。

| 按鍵 | 意義 |
|---|---|
| ↑ ↓ | 移動焦點。九宮格一次跳一列。沒有可選項目的頁面（例如「關於與資料說明」）改成捲動內容 |
| ◀ ▶ | **換分頁**：首頁「關注｜全部作物」、詳情「走勢｜行情｜比價」、其他語言清單換頁。九宮格內在同一列移動，最左欄再按 ◀ 回到「關注」 |
| OK（Enter） | 執行焦點項目；中間軟鍵永遠寫出 OK 會做什麼 |
| 左軟鍵（`Escape`） | 打開底部選單 |
| 右軟鍵 | 返回：關閉面板 → 上一個畫面 → 在首頁時離開 App |
| 1–9 | 直接開啟畫面上標了該數字鍵帽的項目；在面板中直接執行第 N 項 |
| `*` | 批發 ⇄ 零售（只在價格畫面有效） |
| `#` | 這一頁的選項：首頁、作物清單、行情頁、本地區各市場 → 打開「換地區」面板；走勢頁 → 7 日 ⇄ 30 日；比價頁 → 打開排序面板 |
| `0` | 語音播報（加分項 B8），只在行情頁 |

其他規則：
- 方向鍵長按可以連續移動；OK、數字、`*`、`#` 長按不重複觸發。
- 換分頁用「取代」歷史，不新增一筆；所以右軟鍵會回到上一個畫面，不是上一個分頁。
- 面板打開時，按鍵只作用在面板上，不會穿透到後面的畫面。

## 5. 畫面規格

每個畫面都由三部分組成：header（標題）、內容、軟鍵列（左／中／右）。以下的「軟鍵」依序是左、中、右。

### 5.1 首次設定（F01）

| 畫面 | 內容 | 軟鍵 |
|---|---|---|
| 語言 | 手機語言排第一並標「手機語言」；接著是另外兩個語言；हिन्दी 標「→ English・尚未提供」；最後是「🌐 More・其他」（第二行 अन्य） | 空／選取／離開 |
| 其他語言 | 每頁 4 個，◀ ▶ 換頁，每個標「→ English・尚未提供」 | 空／選取／返回 |
| 確認位置 | 「你在 {地區} 附近嗎？」、所屬的邦或區域與國家、「依網路位置推測（不用 GPS，也不保存）」；選項 1「是，就是這裡」、2「不是，我自己選」 | 空／選取／返回 |
| 國家 | 印度、台灣，各附涵蓋範圍 | 空／選取／返回 |
| 地區 | 地區清單（依距離排序） | 空／選取／返回 |

- 推測不到位置時跳過「確認位置」，直接選國家。
- 選了「是」就直接進首頁；首頁的關注作物使用該國的預設清單。

### 5.2 首頁（F02）

- **header**：「{地區}行情」，例如「台北市行情」「Nashik 縣行情」，旁邊畫 `#` 鍵帽。
- **資訊列**：左邊是 `*` 鍵帽加「批發／零售」標籤與單位；右邊是日期（例如「9/19 週六」）。
- **分頁**：◀「關注｜全部作物」▶。
- **關注分頁**：作物卡片清單，每張卡片：
  - 左：作物圖示，前 9 張左上角有數字鍵帽。
  - 中：作物名稱；說明列放品種，資料不是今天時才加註「昨天」「3 天前」（3 天以上用警示色）。
  - 7 日迷你走勢線。
  - 右：價格、漲跌標籤（▲▼＝加百分比）。
  - 沒有資料時價格顯示「—」，說明列寫「尚無零售資料」或「無資料」，不顯示走勢與漲跌。
- **全部作物分頁**：九宮格，位置對應實體鍵 1–9：穀物、蔬菜、水果、豆類、香料、油籽、其他、全部、最近看過。
- **軟鍵**：選單／開啟／離開。

### 5.3 作物清單（F03）

- header：分類名稱。資訊列：左邊是地區名稱加 `#` 鍵帽，右邊是 `*` 批發／零售與單位。
- 內容：和首頁相同的作物卡片。
- 軟鍵：選單／開啟／返回。

### 5.4 作物詳情（F04）

- header：作物名稱。
- 資訊列：左邊是地區名稱（行情頁才加 `#` 鍵帽）；右邊是 `*` 批發／零售標籤，以及資料時間（今天就寫「9/19 11:40」，不是今天就用警示色寫「昨天」等）。
- 分頁：◀「走勢｜行情｜比價」▶，預設「行情」。

**行情分頁**
- 大數字卡：作物圖示、說明（批發：「{n} 個市場中位數 · 單位」，只有一個市場時寫「僅 1 個市場」；零售：「零售調查價 · 單位」）、價格、漲跌標籤與「+95 較前一交易日」；右上角有 `0` 鍵帽與喇叭圖示（語音加分項）。
- 批發時：「本地區 {N} 個市場」卡片，說明列寫「最高 X・最低 Y」（只算今天有報價的市場），右側有 `OK ›`；這是本頁第一個可選的項目。
- 零售時：說明「零售價以地區為單位，沒有市場細項」。
- 三個指標：比 7 日均價、到貨量（零售改成「波動」）、30 日位置（附小量表）。
- **附近最高／最低**（2026-09-20 追加）：指標下方最多兩張地區卡片，告訴使用者附近哪個地區價格最高、哪個最低；跟著目前的批發／零售，單位和本頁相同。
  - 附近＝同一個國家內離這個地區最近的 **3 個**地區，而且直線距離 **300 km 以內**。只比最新交易日和這個地區**相同**的地區；這個地區的價格要是新的（今天，或中間只有休市日）。所以卡片不另外標日期，日期看資訊列。
  - 每張卡片：路線圖示（左上角數字鍵帽）、地區名稱、說明列「附近最高 · 直線 165 km」（英文「Highest · 165 km (straight)」）、價格、和這個地區的差額。OK 或數字鍵打開那個地區的行情分頁，和比價頁選地區相同。
  - 這個地區本身就是最高（或最低）時，那一張改成這個地區自己的卡片：定位圖示、地區名稱、「附近最高」（或「附近最低」）、「你」標籤；不顯示價格（大數字卡已經有）、不能選，而且排在另一張前面，讓最後一張一定是可選的。
  - 這個地區沒有價格或是舊資料、附近沒有符合的地區、或附近都和這裡同價時，不顯示。
  - 用語只寫「附近最高／附近最低」，不分賣方、買方；兩張卡片都能選，賣的人看最高、買的人看最低。
  - 128×160：每張一行（圖示、名稱、價格、漲跌符號），不顯示說明列。
- 軟鍵：選單／市場（焦點在附近的地區卡片時為「查看」；零售時沒有可選的項目則為「比價」）／返回。

**走勢分頁**
- 標題列「7 日走勢」加漲跌標籤；右側是 `#` 鍵帽與「7 日｜30 日」切換鈕（目前的填色）。
- 折線圖：面積填色、今天的點加粗並標數字、休市日斷線並在 X 軸標「休」、右側三條參考線標數值。
- 三個指標：高、低、波動。
- 軟鍵：選單／行情／返回。

**比價分頁**
- 排序列：`#` 鍵帽加目前的排序（預設「價格 高→低」）。
- 名次說明：「{地區} 價格排第 3／10」；沒有資料時寫「未列排名」。
- 各地區卡片：名次、地區名稱、說明列（直線距離 · 市場數 · 舊資料警示）、價格、和目前地區的差額（自己的地區標「你」）。
- 沒有資料的地區排在最後，價格顯示「—」。
- 軟鍵：選單／查看／返回。選了某個地區就打開那個地區的詳情（行情分頁）。

**排序面板**（比價頁按 `#`）：1 價格 高→低、2 價格 低→高、3 距離 近→遠、4 距離 遠→近；目前的打勾。

### 5.5 本地區各市場、單一市場（F05）

- **本地區各市場**：資訊列左邊是地區加 `#`，右邊是 `*` 標籤與單位；說明列「與中位數 X 比較」；市場卡片：名次、市場名稱、距地區中心的公里數（資料不是今天才加註）、價格、和中位數的差額。零售時改成說明「零售價以地區為單位」加「看批發」的選項。
- **單一市場**：市場的代表價（印度常見價、台灣平均價）、漲跌、當日最低到最高的區間條、資料來源。零售時說明「這個市場沒有零售報價」加「看 {地區} 的零售價」。

### 5.6 換地區（F07）

- **面板**（`#`）：最近用過的 3 個地區（目前的打勾）＋「其他地區…」。
- **地區清單**：最近使用、全部地區（依直線距離排序）；每列有地區名稱、所屬的邦或區域、直線距離、資料狀態點（今天有資料不寫字，只有例外才寫「昨天」「3 天前」「無資料」）；最後一項「更改國家…」。
- 在首頁或作物清單換的是「我的地區」；在詳情頁、市場畫面換的是「正在看的地區」，不改「我的地區」。

### 5.7 其他畫面

| 畫面 | 內容 |
|---|---|
| 左軟鍵選單（F08） | 底部彈出面板，項目帶數字鍵帽與圖示 |
| 編輯關注（F09） | 所有作物的勾選清單，OK 切換 |
| 設定（F10） | 五列，每列右側顯示目前的值；OK 切換或打開對應清單 |
| 關於與資料說明（F11） | 可捲動的說明卡片 |
| 離開後重開（F13） | 按首頁右軟鍵離開；重新開啟回到原畫面與焦點 |

## 6. 狀態規格（F12）

| 狀態 | 顯示 | 出口 |
|---|---|---|
| 載入中 | 卡片骨架（靜態，不閃爍）＋「正在取得 {地區} 的行情…」「超過 10 秒會顯示錯誤」 | 右軟鍵可返回 |
| 連線失敗 | 首頁最上方一張警示卡「連線失敗・先顯示 09:12 的資料」，每張作物卡改標「舊」；詳情頁顯示錯誤說明 | 中間軟鍵「重試」 |
| 地區今天未更新 | 「{地區} 今天還沒更新」「這個地區通常 14:00 前更新」「最近一筆（3 天前）：X」 | 1 看其他地區、2 看走勢 |
| 沒有零售資料 | 「尚無零售資料」＋原因（作物沒有零售回報，或零售以地區為單位） | 「看批發」 |
| 沒有資料 | 價格「—」、說明「無資料」；不顯示 0、不畫走勢 | — |

- 請求逾時 10 秒進入錯誤狀態，不無限等待。
- 有舊資料時保留舊資料並標示，沒有才顯示錯誤畫面。
- 休市日不補 0，走勢圖斷線。

## 7. 驗收條件（baseline 完成的定義）

- 只用方向鍵、OK、左右軟鍵、0–9、`*`、`#` 就能走完：首次設定 → 首頁 → 作物詳情三個分頁 → 本地區各市場 → 單一市場 → 比價 → 換地區 → 設定，且每一層都能返回。
- 240×320 與 128×160 兩種尺寸：固定畫面沒有溢出，清單的焦點項目永遠在可見範圍內，焦點永遠看得見。
