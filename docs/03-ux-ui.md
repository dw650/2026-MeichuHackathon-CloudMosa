# 03 UI／UX 規格

> 「收成卡片」設計系統。數值取自互動草圖 [`ui-mockup/`](ui-mockup/)（樣式在 `ui-mockup/src/phone.css`），正式實作以本文與草圖為準。
> 所有尺寸都是初始值，拿到實機後依 [08](08-platform-constraints.md) 的待驗證清單校正。

## 1. 設計原則【決定】

1. **打開就有答案**：首頁直接顯示關注作物的價格，不需要先選東西。
2. **按鍵意義固定**：◀ ▶ 永遠換分頁、`*` 永遠是批發／零售、`#` 是這一頁的選項、1–9 直接開啟、左軟鍵選單、右軟鍵返回。
3. **每個提示只出現一次**：按鍵提示就畫在它控制的東西旁邊（`*` 在批發／零售標籤旁、`#` 在地區名稱或切換鈕旁、◀ ▶ 在分頁兩側、數字在項目的圖示上）。**不做**整條按鍵提示列，也不在同一畫面重複寫同一件事。
4. **誠實**：缺資料就說缺，不補 0；不是今天的資料一定標示；說明文字集中在「關於與資料說明」頁，不塞在主畫面。
5. **不動**：沒有動畫、跑馬燈、輪播、自動刷新、閃爍的載入圖示（每次畫面變動都耗手機流量）。
6. **單欄**：不靠左右並排比較；一屏一個重點。

## 2. 版面骨架

```
┌──────────────────────┐
│ （系統狀態列，待確認） │
│ header：標題          │ 40px（128×160：20px）
├──────────────────────┤
│ 資訊列：地區／批零／日期 │ 22px（14px）
│ 分頁（有的畫面才有）    │
│ 內容（可捲動）          │

```

| 區塊 | 240×320 | 128×160 |
|---|---|---|
| header | 40px | 20px |
| 內容區 | 其餘高度（無狀態列時 252px） | 其餘高度（122px） |
| 軟鍵列 | 28px | 18px |

- 用 CSS grid 排三列：`grid-template-rows: var(--hdr) minmax(0, 1fr) var(--sk)`；外框高度取實際 `innerHeight`，不寫死 320。
- 若實機有系統狀態列占用高度：240×320 的 header 壓縮成 30px、128×160 壓縮成 16px（草圖的「系統狀態列：預留 20px」可預覽）。

## 5. 焦點與捲動【決定】

- 同一時間只有一個焦點，而且永遠看得見；用真正的 DOM 焦點，不只是畫樣式。
- 進入新畫面時焦點在第一個可選項目；返回時依**項目 ID**（不是索引）還原焦點與捲動位置。
- 焦點移出可見範圍時立即捲動（不用平滑捲動），並留 6px 邊距；焦點是第一項且放得下時，捲到最上面，讓資訊列一起露出來。
- 面板打開時焦點鎖在面板內；關閉後回到原本的項目。
- 沒有可選項目的頁面，↑ ↓ 一次捲動 60% 高度。

## 6. 128×160 縮減規則【決定】

不等比縮小，而是重新排版：

- 清單改成單行：圖示、名稱、價格、漲跌符號（不帶百分比）；不顯示迷你走勢與說明列。
- 資訊列只留地區或主要資訊；不畫鍵帽（數字鍵、`*`、`#` 照常可用）。
- 分頁兩側不畫 ◀ ▶。
- 行情頁不顯示作物圖示與三個指標；走勢圖不畫刻度文字。
- 面板只顯示數字鍵帽與文字。

## 7. 文字與格式【決定】

- **介面文字全部走 i18n 字串**，不寫死在元件裡；繁中與英文要完整，含錯誤、空狀態、軟鍵。
- **數字**：用 `Intl.NumberFormat`，locale 依國家（印度 `en-IN`，會用 lakh 分組；台灣 `zh-TW`）。
- **單位**：每個畫面只寫一次（資訊列或大數字卡）。印度批發預設 ₹/公擔、零售 ₹/公斤；台灣預設元/公斤，可改元/台斤。小數位數依單位設定。
- **日期**：繁中「9/19 週六」，英文「Sat 19/9」；資料時間「9/19 11:40」。
- **名稱**：長名稱用省略號截斷，完整名稱在詳情頁的 header。數字永遠不截斷。
- **用語一致**：地區、市場、批發、零售、關注、比價等用 [00](00-overview.md) 名詞表的說法。

## 8. 圖示【決定】

- 作物圖示是自己畫的彩色 SVG（24×24 viewBox），每種作物都不同；分類圖示沿用代表作物。**不用 emoji**。
- 介面圖示是單色線條 SVG（定位、日曆、時鐘、商店、排序、喇叭、地球、設定等），顏色跟著文字。
- 原始 SVG 在 `ui-mockup/src/icons.js`，正式實作直接搬過去。2026-09-20 追加的 13 種作物與馬來西亞的 8 種（黃瓜、胡蘿蔔、長豆、四季豆、薑、萊姆、金桔、椰子；06 §7.3）草圖沒有，圖示直接畫在 `frontend/src/icons/crops.tsx`，風格與原本的相同；測試會檢查每個國家的每種作物都有自己的圖示。

## 9. 如何使用草圖

- 打開 [`ui-mockup/index.html`](ui-mockup/index.html)：「互動試玩」可用鍵盤或畫面上的按鍵操作；「全部畫面」一次顯示所有畫面的兩種尺寸。
- 網址參數：`?mode=gallery`、`?country=TW`、`?lang=en`、`?ip=none`（模擬推測不到位置）、`?zoom=2`、`?audit=1`（在「全部畫面」模式列出每個畫面的垂直溢出 px）。
- 修改草圖：改 `ui-mockup/src/` 的檔案，再執行 `python3 docs/ui-mockup/build.py` 合併成單一 HTML（Flatpak 版瀏覽器只能讀單一檔案）。
- 草圖是用原生 JS 寫的參考實作，**不要直接複製成正式程式**；正式前端用 React 元件重寫（見 [04](04-architecture.md)）。
